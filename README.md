# AI 기반 발표 피드백 시스템

발표자의 영상을 업로드하면 AI가 비언어적 표현, 음성 전달, 매체 활용 등 3개 영역 12개 항목을 분석하고 타임스탬프 기반의 구체적인 피드백을 제공합니다.

---

## 화면 흐름

로그인 → 대시보드 → 분석 준비 → 영상 업로드 → 분석 로딩 → 분석 결과

---

## 주요 기능

### 발표 분석 준비

영상 분석 전 발표 맥락 정보를 입력합니다.

- 발표 주제 입력
- 청중 유형 선택 (일반 대중, 전문가, 학생, 임원 등)
- 발표 시간 입력 (선택)
- 발표 자료 PDF 업로드 (선택) - 자료와 발표 내용의 정합성 분석에 활용
- 피드백 받을 항목 선택 (카테고리별 그룹 제공, 전체 선택/해제 지원)
- 추가 분석 조건 입력 (선택, 최대 6개) - 특정 조건의 충족 여부 판단

### 피드백 영역

3개 카테고리, 총 12개 세부 항목으로 구성됩니다.

**시각적 수치 및 신체 활용 (Visual & Body)**

| 항목 | 설명 |
|------|------|
| 시선 접촉 | 카메라 렌즈를 응시하며 청중과 눈을 맞추는 빈도와 적절성 |
| 얼굴 표정 | 메시지의 감정과 의미를 강화하는 안면 근육의 움직임 |
| 제스처 | 화면 범위(Camera frame) 내에서 메시지를 강조하는 손동작 |
| 언어-비언어 동기화 | 말의 내용과 표정, 손짓이 시간적으로 일치하는 정도 |
| 비언어적 청중 인식 | 화면 너머의 청중을 인지하고 있음을 보여주는 미세한 반응 |
| 방해 동작 지양 | 카메라 앞에서 불필요하게 몸을 흔들거나 만지는 산만한 습관의 부재 |
| 청중 대면 | 신체의 방향이 정면(카메라)을 올바르게 향하고 있는 상태 |

**음성 전달 수행 (Verbal & Vocal)**

| 항목 | 설명 |
|------|------|
| 구어 표현 및 준언어 | 목소리의 톤, 속도, 크기 등을 조절하여 전달력을 높이는 능력 |
| 언어 선택 | 텍스트의 정교함과 상황에 맞는 단어 사용 능력 |
| 청중 적응 | 화면 반응에 따라 발표 내용을 유연하게 조정하는 능력 |

**매체 및 환경 관리 (Media & Professionalism)**

| 항목 | 설명 |
|------|------|
| 기술 및 매체 상호작용 | 화면 공유, 슬라이드 넘기기 등 디지털 도구를 매끄럽게 다루는 능력 |
| 전문적 외양 | 카메라에 비치는 복장과 배경이 발표 맥락에 부합하는 정도 |

### 분석 결과

- 종합 피드백: 전체 발표에 대한 강점 3개, 개선 제안 3개, 요약 텍스트
- 타임스탬프 피드백: 영상 내 특정 시점에 대한 항목별 피드백 (10~15개), 클릭 시 해당 위치로 영상 자동 이동
- 발표 자료 정합성 분석: 자료 업로드 시 자료와 실제 발표의 일치/불일치 항목 분석 (선택)
- 조건 충족 분석: 사용자가 입력한 조건의 충족 여부 판단 (선택)

### AI 성찰 대화

분석 결과를 컨텍스트로 활용하는 AI 채팅 패널을 제공합니다. 발표에 대해 자유롭게 질문하거나 구체적인 개선 방법을 상담할 수 있습니다.

## 기술 스택

| 항목 | 내용 |
|------|------|
| 프레임워크 | Next.js 14.2.5 (App Router) |
| AI 분석 | Google Gemini 2.5 Flash (영상 멀티모달 분석) |
| AI 대화 | Google Gemini 2.0 Flash (채팅) |
| 영상 저장 | Vercel Blob (업로드 후 분석 완료 시 자동 삭제) |
| 클라이언트 버퍼 | IndexedDB (영상 파일 임시 저장) |
| 상태 공유 | sessionStorage (페이지 간 준비 데이터 및 분석 결과 전달) |

## 환경 변수

`.env.local` 파일에 아래 변수를 설정해야 합니다.

```
GEMINI_API_KEY=...
BLOB_READ_WRITE_TOKEN=...
```

---

## 실행 방법

```bash
npm install
npm run dev
```

로컬 접속 주소: `http://localhost:3000`

테스트 계정: 아이디 `1` / 비밀번호 `1212`

## 디렉토리 구조

```
app/
  page.js                  로그인
  dashboard/page.js        대시보드 (더미 피드백)
  prepare/page.js          분석 준비 (발표 정보 + 항목 선택)
  upload/page.js           영상 업로드
  loading/page.js          업로드 및 분석 진행
  analysis/page.js         분석 결과 + AI 성찰 대화
  api/
    analyze/route.js       Gemini 영상 분석 API
    chat/route.js          Gemini 성찰 대화 API
    upload-blob/route.js   Vercel Blob 업로드 핸들러
  lib/
    feedbackAreas.js       피드백 카테고리/항목 정의 (공통 소스)
```
