# AI 기반 발표 피드백 시스템

발표자의 영상을 업로드하면 AI가 내용, 조직, 표현의 3개 영역 16개 하위 영역을 분석하고 타임스탬프 기반의 구체적인 피드백을 제공합니다.

---

## 화면 흐름

로그인 → 대시보드 → 분석 준비 → 영상 업로드 → 분석 로딩 → 분석 결과

---

## 주요 기능

### 발표 분석 준비

영상 분석 전 발표 맥락 정보를 입력합니다.

- 발표 주제 입력
- 청중 유형 선택 (일반 대중, 전문가, 학생, 임원 등)
- 발표 시간 입력 (선택)
- 발표 자료 PDF 업로드 (선택) - 자료와 발표 내용의 정합성 분석에 활용
- 피드백 받을 항목 선택 (카테고리별 그룹 제공, 전체 선택/해제 지원)
- 추가 분석 조건 입력 (선택, 최대 6개) - 특정 조건의 충족 여부 판단

### 피드백 영역

3개 카테고리, 총 16개 세부 항목으로 구성됩니다.

**내용**

| 항목 | 설명 |
|------|------|
| 주제 적절성 | 청중과 발표 상황에 적절한 주제를 선정하였다. |
| 어휘 및 표현 적절성 | 상황과 맥락에 적절한 어휘를 선택하여 표현하였다. |
| 문법 및 언어 정확성 | 어법과 문법에 맞게 표현하였다. |
| 청중 맞춤성 | 청중의 수준과 특성을 고려하여 발표 내용을 효과적으로 조정하였다. |

**조직**

| 항목 | 설명 |
|------|------|
| 도입 구성 | 청중이 발표 주제와 발표자에 대해 이해할 수 있도록 도입을 구성하였다. |
| 내용 조직 및 흐름 | 내용 간 연결이 자연스럽고 체계적인 조직 구조를 활용하였다. |
| 문장 완결성 및 명료성 | 한 가지 생각이나 내용을 완결된 문장으로 명확하게 전달하였다. |
| 결론 구성 | 논지를 강화하고 청중이 발표의 마무리를 명확히 인식할 수 있도록 결론을 구성하였다. |

**표현**

| 항목 | 설명 |
|------|------|
| 음성 표현 | 음성 표현과 준언어적 요소(억양, 속도, 강세 등)를 효과적으로 활용하였다. |
| 비언어적 표현 | 언어적 메시지를 보완하는 비언어적 행동을 적절히 활용하였다. |
| 시선 처리 | 청중과 적절한 시선 접촉을 유지하였다. |
| 발음 및 말하기 유창성 | 발음과 말하기 속도가 적절하며 매끄럽게 말하였다. |
| 몸짓 및 움직임 | 전달 내용을 효과적으로 지원하는 움직임과 몸짓을 활용하였다. |
| 태도 및 복장 | 발표 상황과 맥락에 적절한 복장과 태도를 유지하였다. |
| 불필요한 움직임 통제 | 산만하거나 불필요한 신체 움직임을 보이지 않았다. |
| 매체 활용 | 기술 및 매체를 발표 목적에 맞게 적절히 활용하였다. |

### 분석 결과

- 종합 피드백: 전체 발표에 대한 강점 3개, 개선 제안 3개, 요약 텍스트
- 타임스탬프 피드백: 영상 내 특정 시점에 대한 항목별 피드백, 클릭 시 해당 위치로 영상 자동 이동
- 발표 자료 정합성 분석: 자료 업로드 시 자료와 실제 발표의 일치/불일치 항목 분석 (선택)
- 조건 충족 분석: 사용자가 입력한 조건의 충족 여부 판단 (선택)

### AI 성찰 대화

분석 결과를 컨텍스트로 활용하는 AI 채팅 패널을 제공합니다. 발표에 대해 자유롭게 질문하거나 구체적인 개선 방법을 상담할 수 있습니다.

## 기술 스택

| 항목 | 내용 |
|------|------|
| 프레임워크 | Next.js 14.2.5 (App Router) |
| AI 분석 | Google Gemini 2.5 Flash (영상 멀티모달 분석) |
| AI 대화 | Google Gemini 2.0 Flash (채팅) |
| 영상 저장 | Vercel Blob (업로드 후 분석 완료 시 자동 삭제) |
| 클라이언트 버퍼 | IndexedDB (영상 파일 임시 저장) |
| 상태 공유 | sessionStorage (페이지 간 준비 데이터 및 분석 결과 전달) |

## 환경 변수

`.env.local` 파일에 아래 변수를 설정해야 합니다.

```
GEMINI_API_KEY=...
BLOB_READ_WRITE_TOKEN=...
```

## 실행 방법

```bash
npm install
npm run dev
```

로컬 접속 주소: `http://localhost:3000`

테스트 계정: Firebase Auth에 생성된 테스트 이메일 계정 사용

## 디렉토리 구조

```
app/
  page.js                  로그인
  dashboard/page.js        대시보드 (더미 피드백)
  presentations/[id]/page.js 발표 상세 + 영상 업로드/시뮬레이션 시작
  loading/page.js          업로드 및 분석 진행
  analysis/page.js         분석 결과 + AI 성찰 대화
  api/
    analyze/route.js       Gemini 영상 분석 API
    chat/route.js          Gemini 성찰 대화 API
    upload-blob/route.js   Vercel Blob 업로드 핸들러
  lib/
    feedbackAreas.js       피드백 카테고리/항목 정의 (공통 소스)
```
